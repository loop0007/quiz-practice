## 10. 限制与后续

- **Linux/WSL 实测**：当前环境无 WSL、无 Docker，无法执行 T5 的 Linux 安装/构建/预览。已用大小写敏感的静态检查预检，但不等同于实测。
- **真机验收**：375/390 为无头 Edge 设备模拟，不是真机；手机蜂窝网络、另一台电脑与真机单手操作仍随 M10 复验。
- **e2e 不进入 CI**：GitHub Actions 运行 `npm test` 与构建；浏览器验收依赖本机 Edge。
- 每次修复缺陷后至少补跑 `npm test`、`npm run check:source` 与相关 e2e 场景。
