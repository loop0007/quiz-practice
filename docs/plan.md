## 4. 功能清单

- **练习**：首页统计与进度、两套题库、章节/题型筛选、继续上次练习、逐题提交判分、答案解析、上一题/下一题、题号侧栏与移动端抽屉、交卷确认、结果统计、错题重练、键盘快捷键。
- **复习**：错题本跨练习累计、按题库分组折叠、答案与解析对照、首次答错时间、批量移除、分组重练；收藏与取消收藏、分组折叠、批量取消；历史成绩汇总与结果页跳转；题目/主页反馈。
- **体验**：桌面原文字导航与“三”菜单、移动端顶栏五入口、使用说明、深色模式、四套壁纸与本机图片、四种动态特效、开场模糊/首屏/页面切换/悬停动效、响应式与无障碍、PWA 离线与下载为应用。
- **边界**：数据仅存本机 IndexedDB/localStorage；不做账号、云端同步、排行榜、成就与运行期题库上传。

## 5. 架构与固定规则

```text
pages（页面编排）
  → components（展示与交互）
  → store（当前会话状态与动作）
  → lib（判分、存储、主题、特效等纯逻辑）
  → types（共享契约）
  → data/banks.json（解析产物）
```

- 页面不直接操作 Dexie 表，统一通过 `lib/db.ts`；判分只在 `lib/scoring.ts` 实现。
- `lib` 不反向依赖 `pages/components`；题库 JSON 只由脚本生成，不手改。
- 每场练习保存 `questionIds` 快照，结果统计以快照为准；答案记录首次提交后不可改。
- 额外功能以新模块、新路由或新表加入，不改核心 Session 与判分契约。
- 构建产物 `dist/` 必须可独立静态托管：相对路径、无本地绝对路径、无运行时后端。
- 接口冻结范围：`BankData`、`PracticeSession` / `AnswerRecord` / `WrongEntry` / `FavoriteEntry`、db API、scoring API、题目渲染 props、主题 token。

## 8. 风险与应对

| 风险 | 应对 |
| --- | --- |
| Markdown 题库格式不统一 | 解析脚本跟踪代码围栏，异常题不进入练习并单独报告 |
| 判分或统计口径分散 | 只允许 `scoring.ts` 实现，页面复用同一统计函数 |
| 双击/重复提交 | 首次提交幂等，提交后锁定选项与按钮 |
| 手机、深色与长题干布局 | 375/390 与 1280 无头回归，代码块横向滚动，44px 触控目标 |
| 子路径部署资源 404 | `base: './'` + HashRouter，发布前检查相对路径 |
| 国内访问 GitHub Pages 不稳 | 必要时把 `dist/` 发布到其他静态托管，站点无需改代码 |
| 误以为多端数据同步 | README 与界面明确数据按 origin 本地保存 |
