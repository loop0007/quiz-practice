# 在线刷题网站

> 基于本地题库的在线刷题网站。目前已实现题库选择、答题、判分、结果页与错题本；异常反馈、移动端/深色体验完善、公网部署与完整测试记录仍在推进中。

## 设计思路

### 目标与场景

- 目标用户：在校学生。
- 核心场景（验收下限，不是加分项）：
  - 熄灯后的宿舍：低亮度下可读，支持深色模式。
  - 床上使用手机：单手可操作，触控目标足够大。
  - 地铁上单手扶栏杆：能完成选题、作答、翻题。
  - 桌面浏览器：完整功能与题号侧栏。
- 界面参考：[Lucide 图标](https://lucide.dev/icons/)、[Mobbin 移动端案例](https://mobbin.com/)、[牛客网布局](https://www.nowcoder.com/)。

### 功能范围

一期核心（先保证完整跑通）：

- 题库加载与选择（Java、Web 两套）。
- 题目与选项展示；逐题提交（选择后点“提交答案”，提交即判分并锁定该题），全部完成后可直接交卷；存在未提交题时先提示数量，再次确认后才交卷。
- 上一题 / 下一题；答题进度；实时显示已答、答对数。
- 题号侧栏：未做白、正确绿、错误红，同时配合图标/文字标识。
- 交卷结果页：总题数、已答/答对/答错/未答、正确率（未作答按错误计入）、题库异常题数，以及本次错题与未作答题号。
- 答题记录自动保存；错题本跨多次练习累计，按题库分组，展示题干、你的答案、正确答案、解析与首次答错时间。
- 同题不可重复提交，以第一次结果为准；只要曾经答错就进入错题本。
- 题目异常反馈（一期先存本地）。
- 移动端适配与深色模式（由上述场景决定，属于一期）。

二期（有余力再做）：

- 按题型 / 章节分组。
- 收藏夹、壁纸与主题切换、历史成绩统计、错题组卷练习。
- 后端管理

本期不做：
- PWA 离线、键盘快捷键。
- 账号、云端同步、排行榜、成就。
- 运行期上传/解析题库。
### 页面流

题库选择 → 答题页（题号侧栏 + 上一题/下一题 + 提交/交卷）→ 结果页 → 错题本（历史成绩为二期）。

### 关键设计

- 题目 ID 使用 `bankId:questionNo`：两套题库的题号都从 1 开始，不能只存题号。
- 题库在构建前由脚本转为 JSON 并校验；缺题干、缺答案、答案不在选项、重复题号等记为异常题；无有效答案的题不进入练习和正确率分母，结果页单独展示异常数。
- 答题状态以 Zustand 为唯一数据源，Dexie 负责持久化；各页面从同一份状态派生，避免判分不一致。
- 判分口径统一：每题只允许提交一次，以第一次提交结果计入成绩；重复点击不改变成绩；首次答错进入错题本；正确率分母为题库总题数，未作答按错误计；结果页的“本次错题”与错题本分开统计。
- 提交逻辑幂等：按 `bankId:questionNo` 检查是否已有提交记录，存在则直接返回，避免双击或重复点击写入第二次结果。
- 静态运行：Vite 设置 `base: './'`，路由使用 HashRouter，避免子路径部署与静态服务器的资源、深链接问题。
- 题目文本含行内代码与代码块（如 `<video>`、`str.charAt(1)`），渲染时按文本/代码处理，不使用未消毒的 HTML 注入。

## 运行方式

> 脚手架建立后按实际命令校正。验收会在 Linux 服务器上运行（考题要求），命令需跨平台，不依赖 Windows 路径。

- 环境要求：Node.js 20.19+ 或 22.12+、npm 10+。
- 安装依赖：`npm install`
- 本地开发：`npm run dev -- --host`
- 单元测试：`npm test`
- 构建：`npm run build`（构建前会自动重新解析题库）
- 预览构建产物：`npm run preview -- --host`
- 访问地址：开发默认 `http://localhost:5173`，预览默认 `http://localhost:4173`。
- 交付时附带构建后的 `dist/`，验收机可用静态服务器直接运行，减少现场构建依赖。
- 说明：本项目是 Vite 单页应用，不能直接双击源码 `index.html`；需通过上述命令或静态服务器访问。交付构建产物时可用 `python3 -m http.server -d dist 8080`。
- Linux 注意：文件系统区分大小写，`import` 路径必须与文件名大小写一致；不要使用 Windows 专属路径或命令。

### 公网访问（手机 / 其他电脑）

- 构建后把 `dist/` 发布到任意静态托管平台：GitHub Pages、Netlify、Vercel、Cloudflare Pages，或国内访问更稳的腾讯 EdgeOne Pages / 云厂商对象存储静态托管。
- 发布步骤：`npm run build` → 上传 `dist/`（或配置 Git 自动构建，构建命令 `npm run build`，产物目录 `dist`）→ 获得 HTTPS 网址。
- 无需服务端 rewrite：`base: './'` + HashRouter 已兼容子路径部署，刷新 `#/practice/...` 深链接不会 404。
- 验证方式：手机**关闭 Wi-Fi 用蜂窝网络**打开网址，另一台电脑也打开一次，各完成一套练习。
- 数据说明：答题记录和错题本保存在浏览器 IndexedDB 中，按设备与 origin 隔离；手机、电脑、不同域名之间不会同步，换设备相当于从零开始（账号与云端同步不在本期范围）。
